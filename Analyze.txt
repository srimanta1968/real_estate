 Chrome Web Store Submission Guide

  Step 1: Register as a Developer

  1. Go to https://chrome.google.com/webstore/devconsole
  2. Sign in with your Google account
  3. Pay the one-time $5 registration fee
  4. Accept the Developer Agreement

  Step 2: Upload the Extension

  1. Click "New Item" in the Developer Dashboard
  2. Click "Upload" and select: extension/dealeval-extension-v1.0.0.zip
  3. Wait for the upload to process (should take a few seconds)

  Detailed Description (paste this):
  DealEval helps real estate professionals instantly evaluate investment properties by extracting listing data from major real estate websites.

  SUPPORTED SITES:
  - Zillow - Residential listings
  - Realtor.com - Residential listings
  - Redfin - Residential listings
  - LoopNet - Commercial listings
  - Crexi - Commercial listings
  - Trulia - Residential listings
  - CommercialCafe - Commercial listings

  KEY FEATURES:
  - One-click property data extraction from listing pages
  - Multi-site search across all supported sites simultaneously
  - Automatic data forwarding to DealEval web app for analysis
  - Investment metrics: Cap Rate, Cash-on-Cash, IRR, DSCR, GRM
  - Side-by-side property comparison
  - PDF report generation with professional formatting
  - 10-year financial projections

  HOW IT WORKS:
  1. Install the extension and navigate to any supported listing site
  2. The extension automatically detects property listings
  3. Click "Extract" to pull property data into DealEval
  4. View instant investment analysis with key financial metrics
  5. Compare multiple properties and export PDF reports

  PRIVACY:
  - No tracking or analytics
  - Data stays between your browser and DealEval
  - See our full privacy policy for details

  DealEval is the fastest way for agents, investors, lenders, and brokers to evaluate real estate deals using institutional-grade financial metrics.

  Tab 2: Screenshots (REQUIRED - you need to create these)

  Chrome requires at least 1 screenshot (1280x800 or 640x400). Recommended: 3-5 screenshots.

  Screenshots to take:
  1. Popup UI — Show the extension popup with the Extract/Search tabs
  2. Search Results — Show DealEval search page with scraped property cards
  3. Comparison View — Show the comparison page with metrics table and charts
  4. PDF Report — Show a generated comparison PDF
  5. Dashboard — Show the enhanced dashboard with sorted properties

  To take screenshots at the right resolution:
  1. Open Chrome DevTools (F12)
  2. Click the device toggle (Ctrl+Shift+M)
  3. Set resolution to 1280x800
  4. Take screenshot (Ctrl+Shift+P → "Capture screenshot")

  Step 4: Submit for Review

  1. Click "Submit for Review"
  2. Google typically reviews within 1-3 business days
  3. You'll get an email when approved or if changes are requested

  Step 5: After Approval

  Once approved, your extension gets a Chrome Web Store URL like:
  https://chrome.google.com/webstore/detail/dealeval-property-data-ex/[EXTENSION_ID]

  You can then:
  - Share this link with users
  - Update the extension by uploading a new zip with a bumped version number
  - View install analytics in the Developer Dashboard

  Updating the Extension Later

  1. Bump version in manifest.json (e.g., "1.0.0" → "1.1.0")
  2. Run bash extension/build-extension.sh
  3. Upload the new zip in Developer Dashboard → your extension → "Package" tab
  4. Submit for review again
